# AIGC 美学定义 Skill

> **把画面拆成可执行的美学参数，再写提示词。**
> [English](README.en.md)

一个给 AI 编码助手（Claude Code / Codex / DeepSeek Harness 等）用的技能包：写人物定妆照、三视图、剧照、场景图、视频首帧的提示词时，按「光 → 材质 → 风格 → 镜头」拆解，避免形容词堆叠和 AI 味。

## 解决什么问题

- **画面「平」**：只有「电影感」，没有光位、光比、色温
- **塑料感 / 像 CG**：材质只写形容词，没有反射方式与缺陷
- **风格跑偏**：混入插画、游戏、流派词，把写实拉成「画」
- **人物前后不是同一人**：没有参考图与一致性锚点
- **可数特征数量错**：多条尾巴画成一条、多条触手画成五条

## 安装

```bash
git clone https://github.com/JulesCesar/aigc-aesthetic-definition.git \
  ~/.agents/skills/aigc-aesthetic-definition
```

也可把整个目录复制到 `~/.agents/skills/`（Claude Code 用户可用 `~/.claude/skills/`）。

## 用法

直接用自然语言提需求：

- 「给我写一个 xx 角色夜戏的提示词」
- 「这张图发平，按美学定义诊断一下」
- 「这个风格词该不该加」

助手会加载本技能，按「主体 → 光 → 材质 → 镜头 → 画质 → 负面」输出可复制的整段提示词。

## 一条核心原则

> **写物理，不写形容词。**

不写「高级感」，写「单一 45° 柔光，5600K，光比 1:3，光落在鼻梁与颧骨」。

## 边界

本仓库只含方法、判断标准与通用模板，**不含任何具体项目的剧本、角色设定、场景描述或原书内容**。
