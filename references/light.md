# 光：四维 + 落点

## 1. 光源
自然光（日光/月光/天光）｜人工光（灯/火/屏幕/激光）

## 2. 质感
硬光：明暗交界锐利、阴影深、材质强
柔光：过渡平缓、反差小、肤质柔和

## 3. 光位（书第 16–20 节）
| 光位 | 效果 | 情绪 |
|---|---|---|
| 面光 | 平、安全、少立体 | 中性、档案 |
| 全侧光 | 立体、反差大 | 压抑、严肃、对峙 |
| 逆光 | 剪影、轮廓 | 神圣、分离、告别 |
| 顶光 | 眼窝阴影 | 审判、威压 |
| 底光 | 阴影向上翻 | 诡异、非人、炉火 |
| 伦勃朗位 | 侧上 45°，暗侧颊三角光斑 | 古典、有故事 |

## 4. 光色
暖 2700–3200K｜中性 5000–5600K｜冷 6500–7500K｜月光 4300K

## 5. 写落点（关键）
不写「侧光」，写「光落在鼻梁、颧骨、锁骨；左颊留三角光斑」。
- 兽：光落在耳缘、尾尖，毛边发亮
- 龙：光沿鳞缘走，背脊红鬃透光
- 器物：点光只照亮口沿一圈

## 6. 光比
1:2 柔和｜1:3 常规｜1:4 压抑｜1:5 强戏剧

## 速查句
- 定妆照：45° 柔光 + 白卡补光，5600K，1:3
- 夜：月光 4300K 主光 + 1800K 实用光，1:4
- 逆光：低角度逆光勾边，正面补 1 档，体积光可见
