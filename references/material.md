# 材质：写反射方式与缺陷

| 对象 | 中文写法 | English |
|---|---|---|
| 皮肤 | 可见毛孔、鼻翼油光、细纹、耳廓透光 | visible pores, oily nose, fine lines, subsurface scattering |
| 毛发 | 短而密、边缘杂色长毛、逆光毛边 | short dense coat, stray guard hairs, rim-lit edge |
| 有鳞表面 | 湿润反光、鳞缘偏暗、细划痕 | wet specular, darkened scale edges, fine scratches |
| 金属 | 磨损、高点发亮、指纹、氧化 | worn edges, polished highlights, fingerprints, oxidation |
| 玉石 | 半透、内部絮状、油润 | translucent, internal cloudiness, oily luster |
| 青铜 | 凹处绿锈、高点被摸亮 | patina in recesses, polished wear points |
| 织物 | 纤维可见、褶皱硬边、洗旧不破 | visible weave, hard-edged folds, washed not torn |
| 木 | 木纹、裂纹、手磨亮 | grain, cracks, hand-polished sheen |
| 水 | 表面张力、细涟漪、反射破碎 | surface tension, fine ripples, broken reflections |
| TPU/PU | 半透明、有厚度、边缘发亮、褶皱不规则 | translucent TPU, thickness, bright edges, irregular folds |
| 金属闪粉 | 细颗粒反光、随角度变色 | metallic flakes, angle-dependent sparkle |
| 缎面 | 高光随褶皱流动、颜色随角度变深 | satin, moving specular, angle-dependent shift |

## 八个材质方向（书第 3 章）
柔软蓬松｜粗糙手工｜冷硬石材｜梦幻半透明薄纱｜鎏金金属光芒｜迷幻半透明光影｜欢趣高饱和玩具色｜自然复合

## 用法
1. 一张图只写 2–3 种材质，写透
2. 先写反射方式，再写缺陷
3. 不写「质感好」「高级」，写「湿反光 + 细划痕」
