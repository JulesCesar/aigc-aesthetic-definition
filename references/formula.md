# 提示词骨架与场景模块

## 骨架
主体 + 动作/场景 + 风格 + 光（光源/质感/光位/光色）+ 材质 + 镜头 + 画质 + 画幅

## 六种场景光影模块

1. **定妆照**：45° 柔光（伦勃朗位）+ 白卡补光，5600K，1:3；光落在鼻梁/颧骨/锁骨；中性灰背景；35mm 颗粒
2. **三视图**：顶部大面积柔光 + 双侧补光，5600K；浅灰背景；几乎无阴影；无胶片 token
3. **夜戏**：月光 4300K + 实用光 1800K；1:4；暗部留噪点
4. **室内**：单一窗光主光 + 暖灯 2700K 补；木与织物纹理
5. **逆光**：低角度逆光勾边，正面补 1 档；体积光；高光滚降
6. **雨雾**：全漫射；远景发灰；地面湿反光；黑位抬升

## 镜头
24mm 广角｜35mm 环境｜50mm 自然｜85mm 人像｜100mm 微距
f/1.8 极浅｜f/2.8 分离｜f/4 环境可辨｜f/8 全清晰

## 胶片 token（压 AI 味的关键）
Kodak Portra 800（暖、人像）｜Portra 400（中性）｜Ektar 100（高饱和、风光）

## Seedance 视频写法
```
镜头：[机位]+[运动]
光：全程保持 [主光方向/色温] + [环境对比]
主体：[动作]，[材质在光下的反应]
禁忌：无字幕、无水印、不变形、不换脸
```
静态描述不够，光影要写成「镜头内持续状态」。
