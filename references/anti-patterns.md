# 反模式与验收

## 勿用清单
| 别用 | 为什么 |
|---|---|
| 插画/游戏/流派词进人物提示词 | 画面变「画」 |
| 比喻（像孔雀开屏、如灯笼） | 被字面执行 |
| 巨大/宏伟/史诗 | 模型只会加戏 |
| glow / neon / HDR | 塑料感、CG 感 |
| 过度磨皮 / 完美皮肤 | 不像真人 |
| 单写「电影感」 | 等于没写 |

## 十五个翻车点（本项目实测）
1. 只有「影视写实」四个字 → 缺写实杠杆
2. 重绘后着装/发色变了 → 没锁参考图
3. 尖嘴猴腮 → 缺骨相描述、负面没防偶像脸
4. 三视图与定妆照不是同一人 → 没挂参考
5. 可数特征数量错（九尾/触手/引擎）
6. 特写与三视图不一致 → 特写没挂参考
7. 场景材质只写形容词 → 「石头很怪」
8. 穿模 → 出图后不检查
9. 三视图排版乱、背面镜像错 → 没写工程规格
10. 题材俗套化 → 负面没针对题材
11. ChatGPT 与 MJ 混用
12. 重绘时改了原设定
13. 比喻被字面化（孔雀翎）
14. 模型自加符号（额间图腾）
15. 误加插画/游戏/流派词

## 验收表（每张过一遍）
- [ ] 与定妆照同一（不是同类型）
- [ ] 发色/服装/配色一致
- [ ] 可数特征数量对
- [ ] 光源有来源、阴影方向一致
- [ ] 有微纹理、没被磨皮
- [ ] 背景干净、无文字水印
- [ ] 三视图等高、脚底齐平、侧面 90°
- [ ] 背面没有凭空多出正面元素
- [ ] 无穿模、无多余手指
